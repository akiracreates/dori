# Dori Bot -- Телеграм-бот для изучения английской лексики

## 1. Название проекта и назначение

**Dori Bot** --- это Telegram-бот, который помогает студентам
систематически изучать английские слова, а преподавателям --- управлять
общей базой лексики. Бот делает упор на практику, повторение и удобную
работу со словарями.

## 2. Описание проекта

Бот предоставляет:

-   интерфейс **студента** для работы с личным словарём, тренировки в
    режиме флеш-карточек, просмотра слов по модулям и уровням;
-   интерфейс **преподавателя** для добавления, редактирования и
    пакетного добавления слов в базу данных SQLite.

Ключевые функции:

-   разделение ролей *Студент / Преподаватель* (роль преподавателя
    защищена паролем);
-   личный словарь студента (добавление, изменение, удаление слов);
-   обучение с помощью флеш-карточек;
-   структурированная база данных слов по уровням и модулям;
-   локальное хранение данных в SQLite.

## 3. Установка и запуск

### 3.1. Требования

-   Python 3.10+
-   Telegram-бот токен от @BotFather
-   Git

### 3.2. Клонирование репозитория

    git clone https://github.com/akiracreates/dori.git
    cd dori

### 3.3. Виртуальное окружение (рекомендуется)

    python -m venv .venv
    source .venv/bin/activate

### 3.4. Установка зависимостей

    pip install -r requirements.txt

### 3.5. Настройка переменных окружения

Создайте файл `.env`:

    BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
    TEACHER_PASS=ПАРОЛЬ_ПРЕПОДАВАТЕЛЯ

### 3.6. Запуск бота

    python -m bot.main

## 4. Примеры использования

### Роль студента

-   управление личным словарём (добавление / удаление / редактирование);
-   тренировки через флеш-карточки;
-   просмотр слов по модулям;
-   смена уровня.

### Роль преподавателя

-   добавление одного слова;
-   пакетное добавление слов;
-   редактирование существующих слов;
-   просмотр всех слов.
